# Highlights by Outdraw Design

This directory contains the **Highlights** hand-drawn SVG illustration
library by [Outdraw Design](https://highlights.design/), vendored from the
free download kit.

- License: **CC0 1.0** (public domain — free for commercial and personal use)
- Source: https://www.highlights.design/ · https://outdraw.design/
- Files: 117 SVGs across arrows, underlines, loops, blobs, whirls, scribbles,
  lines, donuts, spirals, sprinkles, punctuation, and doodles.
- Colors: original fills are `black` / `#4633FF` (accent). The pipeline
  recolors every fill through the design system's `--ill-*` tokens at compose
  time, so figures follow the active design system (see AGENTS.md).
- The author asks that the library not be used for violence, crime, or animal
  products.
